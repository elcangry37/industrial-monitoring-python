# Industrial Monitoring Python

Proyecto de aprendizaje para desarrollar fundamentos de Python y buenas prácticas de ingeniería de software mediante un sistema básico de monitoreo industrial.

## Funcionalidades

- Carga de información de planta desde JSON.
- Visualización de equipos.
- Selección de equipos por número.
- Validación de selecciones.
- Pruebas automatizadas con pytest.
